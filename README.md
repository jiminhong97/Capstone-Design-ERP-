# Capstone-Design-ERP-

SAP S/4HANA 기반 ERP 구축 프로젝트

## Project Overview

본 프로젝트는 가상의 제조기업을 대상으로
AS-IS 비즈니스 프로세스를 분석하고,
SAP S/4HANA를 활용하여 TO-BE 프로세스를 설계 및 구현하는 것을 목표로 한다.

## Modules

| Module | Description | Assigned To |
|---|---|---|
| PP | Production Planning / 생산관리 | 정유진 |
| MM | Materials Management / 구매 및 자재관리 | 정민혁 |
| SD | Sales and Distribution / 영업 및 판매관리 | 홍지민 |
| FI | Financial Accounting / 재무회계 | 황인형 |
| CO | Controlling / 관리회계 | 장성하 (PM) |

## Current Status

- 산업 후보 탐색 중
- BOM 및 생산공정 난이도 검토 중
- 트렌디하면서 단순한 제조업 중심으로 후보 선정 중
- SD 관점의 판매 프로세스 검토 중
