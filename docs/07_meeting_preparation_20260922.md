## 1. AS-IS 업무 흐름

**AS-IS란?** ERP를 구축하기 전, 고객사가 일을 처리하는 **현재 방식**을 뜻한다. 3주차 보고서의 전화·이메일·엑셀 중심 업무를 하나의 주문 흐름으로 연결하였다.

~~~mermaid
flowchart LR
    A["고객 주문<br/>전화·이메일"] --> B["SD 영업<br/>엑셀에 주문 입력"]
    B --> C["PP 생산<br/>재고·생산량 별도 확인"]
    C --> D["MM 구매<br/>부족 원료 발주"]
    D --> E["PP 제조·포장<br/>완제품 입고"]
    E --> F["SD 출고<br/>고객 납품"]
    F --> G["FI·CO<br/>거래·원가 자료 취합"]
~~~

| 단계 | 현재 업무를 이렇게 설정 |
|---|---|
| ① 주문 접수 | 영업팀이 도매 고객에게서 카카오·모카·솔티드 캐러멜 단백질바 주문을 받아 엑셀에 입력 |
| ② 재고·납기 확인 | 영업팀이 창고와 생산팀에 맛별 완제품 재고 및 생산예정량을 따로 문의한 뒤 납기 안내 |
| ③ 생산계획 | 생산팀이 전달받은 출고 요청과 별도 작업일지를 참고해 생산 수량·순서 결정 |
| ④ 자재 구매 | 부족한 WPC80·향미 프리믹스·바인더·인쇄필름 등을 구매팀이 별도 발주 |
| ⑤ 제조·포장 | 원료 계량·프리믹스 → 바인더 제조·최종 혼합 → 냉각성형·냉각·절단 → 맛별 인쇄필름으로 개별 포장 |
| ⑥ 납품·정산 | 완제품을 출고하고 판매·구매·생산자료를 회계·원가 담당자가 따로 취합 |

**AS-IS의 핵심:** 주문이 들어온 순간에 **해당 맛의 완제품·원재료·포장재 재고, 생산 가능 시점, 납품 가능일**을 한 번에 확인하기 어렵도록 설정한다.

## 2. 모듈별 AS-IS 문제점 및 개선 방향

한 번에 다루기 쉽도록 **모듈당 핵심 문제 1~2개**를 골랐다. 각 사례는 발표할 때 문제 상황 → 영향 → 개선 방향 순서로 설명하면 된다.

| 모듈 | AS-IS 문제 상황 | 업무상 영향 | TO-BE 제안 |
|---|---|---|---|
| **SD** 영업·판매 | 카카오바 100개 주문을 받았지만 맛별 재고와 생산완료일을 즉시 확인하지 못한 채 납기를 약속 | 납기 지연, 부분납품, 고객 불만 | 맛별 완제품 코드로 수주하고 가용재고·납품일 확인 후 납품문서·출고·청구 연결 |
| **MM** 구매·자재 | 카카오 향미 프리믹스나 카카오 전용 인쇄필름의 실물·장부 재고가 서로 다름 | 생산 직전 자재 부족 발견, 긴급구매 발생 | 원재료·포장재를 별도 자재로 등록하고 구매오더·입고·재고를 연결 |
| **PP** 생산 | 갑작스러운 맛별 주문 변경으로 카카오→모카 등 생산순서가 잦게 바뀜 | 원료 준비·세척·라인 설정시간 증가, 생산 지연 | 맛별 수요·BOM·가용자재를 확인하고 공정별 생산계획과 전환시간 고려 |
| **FI** 재무회계 | 구매·입고·납품·판매 자료를 서로 다른 파일에서 취합 | 대금청구·매입송장 대조 지연 및 입력 오류 가능 | 구매송장과 매출청구를 관련 업무문서에 연결하고 회계전표 추적 |
| **CO** 관리회계 | 맛별 원료 투입·폐기·작업시간이 생산오더 단위로 모이지 않음 | 실제 제조원가·맛별 수익성 비교 곤란 | 생산오더별 재료비·작업비를 수집할 범위를 정하고 맛별 계획/실제 원가 비교 |

### 모듈 사이에서 생기는 문제

**SD ↔ PP:** 고객의 희망 납기와 실제 생산 가능일이 불일치할 수 있다.  
**PP ↔ MM:** 생산계획에는 필요한 자재가 계산되어도 향미 원료나 인쇄필름의 실제 입고가 늦으면 작업을 완료할 수 없다.  
**SD ↔ FI:** 물품 출고·청구·수금 시점이 다른데 담당자가 이를 하나의 '판매 완료'로 처리하면 매출채권 추적에 혼선이 생길 수 있다.  
**PP ↔ CO:** 생산실적과 실제 투입량·작업시간이 연결되지 않으면 제품별 원가 비교의 근거가 부족하다.

> **주의:** 여기의 TO-BE는 개선 방향이지, 수업 SAP에 이미 자동 연계가 구현되었다는 뜻이 아니다. 실제 시연 가능 범위는 각 모듈 담당자가 확인한다.

<a id="industry-issues"></a>
## 3. 단백질바 산업 특화 문제 2가지

일반적인 '엑셀 때문에 오류가 발생한다'를 넘어 **우리 제품이라서 나타나는 문제**로 다음 두 가지를 제안한다.

### ① 맛별 인쇄필름 부족 → 미포장 바가 있어도 판매 불가

- **상황:** 카카오 미포장 바는 충분하지만 **카카오 전용 인쇄필름**이 부족하다. 모카·솔티드 캐러멜 필름으로 대체할 수 없으므로 카카오 완제품 포장이 중단된다.
- **관련 모듈:** MM(포장재 구매·재고) → PP(카카오바 BOM 및 개별포장 공정) → SD(판매 가능한 완제품 수량·납기 확인).
- **제안:** 세 맛의 인쇄필름을 각각 VERP 자재로 등록하고 해당 맛의 포장 단계에 필요한 수량을 BOM에 반영한다. 구매·입고 및 생산 가능 수량을 확인한 후 영업이 납기를 안내한다.
- **회의 결정:** 바 1개에 필요한 필름 길이(M), 재고를 어떤 단위로 관리할지, 이 필름을 반제품→완제품 단계의 BOM에 어떻게 연결할지.

### ② 맛 전환에 따른 세척·준비시간 → 납기 지연

- **상황:** 영업에서 카카오바 긴급주문을 받아 모카 생산 중간에 맛을 바꿔 달라고 요청한다. 맛 변경 시 원료 교체·설비 세척·재설정 시간이 생겨 전체 생산일정이 밀린다.
- **관련 모듈:** SD(주문 및 납기 약속) ↔ PP(생산순서·작업시간) ↔ MM(맛별 원료·포장재 준비).
- **제안:** 맛별 생산 수요를 모아서 순서를 정하고, PP가 가능한 생산완료일을 확인한 후 SD가 고객 납품일을 안내하도록 한다.
- **회의 결정:** 맛 전환에 필요한 준비·세척시간을 생산계획에 어느 수준까지 반영할지. 실습 SAP에서 자동 최적화까지 구현한다고 가정하지 않는다.

## 4. 각 모듈의 업무 범위

| 모듈 | 한 문장 역할 | 우리 회사의 예 |
|---|---|---|
| **SD** | 고객 주문을 받고 납품·출고·청구한다 | 카카오바 100 EA 수주, 가용재고 확인, 출고·청구 |
| **PP** | 생산할 수량과 공정을 계획·실행한다 | 카카오바 100개 생산계획, 맛별 BOM·4개 공정 관리 |
| **MM** | 원재료·포장재 구매와 재고를 관리한다 | WPC80, 카카오 프리믹스, 카카오 인쇄필름 발주·입고 |
| **FI** | 구매·판매에 따른 회계거래를 기록한다 | 공급업체 매입채무, 고객 매출채권 관리 |
| **CO** | 제품 원가와 수익성을 분석한다 | 카카오·모카·솔티드 캐러멜 원가 비교 |

**업무 연결:** SD 수주 → PP 생산 필요량 확인 → MM 부족 자재 구매 → PP 생산·입고 → SD 출고·청구 → FI 회계 처리 → CO 원가 분석. 이는 **전체 흐름을 이해하기 위한 순서**이며 모든 단계가 판매오더 하나로 자동 실행된다는 의미는 아니다.

## 5. 모듈별 조직구조 및 SD 구조 그림

### 5-1. 조직구조 1차 제안

우선 **국내 법인 1개 + 국내 생산공장 1개**에서 5개 모듈을 연결하는 구성이다. 해외 판매·해외법인은 향후 확장안이며, 이번 회의에서 필수 여부를 확인한다.

| 모듈 | 조직구조(쉽게 읽기) | 1차 설계 제안 |
|---|---|---|
| **FI** | Company Code = 회계장부를 관리하는 회사 단위 | 머슬앤허슬 국내 회사 1개 |
| **CO** | Controlling Area = 원가·비용 관리영역 | 관리회계영역 1개, 생산·영업 원가센터 필요성 확인 |
| **MM** | Plant = 공장, Storage Location = 공장 안의 재고 관리 구분, Purchasing Org. = 구매조직 | 공장 1개, 원재료·반제품·완제품 저장위치, 구매조직 1개 |
| **PP** | Work Center = 생산작업장, Routing = 작업 순서 | 보고서의 원료 계량·프리믹스 / 바인더·혼합 / 냉각성형·절단 / 개별포장 4개 주요 공정 |
| **SD** | Sales Org. = 영업조직, Distribution Channel = 판매경로, Division = 제품군, Shipping Point = 출하지점 | 국내영업 1개, 도매 우선, 단백질바 제품군 1개, 공장 출하지점 1개 |

### 5-2. 내 담당 SD 조직구조 그림

**그림 읽는 법:** 고객 주문은 국내영업조직의 **도매 채널**에서 받되, 판매할 물건은 **국내 생산공장**의 완제품 재고에서 출고한다. 아래는 팀에서 검토할 **코드 제안**이며 SAP에 등록된 값은 아니다.

~~~mermaid
flowchart TB
    A["머슬앤허슬 국내 법인<br/>Company Code: MH01"]
    B["국내 영업조직<br/>Sales Organization: MH30"]
    C["도매 유통경로<br/>Distribution Channel: 10"]
    D["단백질바 제품군<br/>Division: 01"]
    S["판매영역 Sales Area<br/>MH30 + 10 + 01"]
    P["생산공장 Plant: MH10"]
    W["완제품 저장위치<br/>Storage Location: FG01"]
    H["공장 출하지점<br/>Shipping Point: MH40"]
    A --> B
    B --> C
    C --> D
    D --> S
    A --> P
    P --> W
    P --> H
    S -. "도매 주문의 제품을 출고" .-> H
~~~

| SD 구성 요소 | 역할 | 회의용 제안 |
|---|---|---|
| Sales Organization | 어느 영업조직이 판매하는가 | MH30 / 국내영업 |
| Distribution Channel | 어떤 경로로 판매하는가 | 10 도매 우선, 20 온라인은 확장 검토 |
| Division | 어떤 제품군을 판매하는가 | 01 단백질바 |
| Sales Area | 위 세 값을 합친 판매영역 | MH30 + 10 + 01 |
| Plant / Storage Location | 어느 공장의 어느 재고를 출고하는가 | MH10 / FG01 |
| Shipping Point | 어디서 납품·출고를 처리하는가 | MH40 |

**맛별 제품 구분:** 카카오·모카·솔티드 캐러멜은 Division을 3개 만들기보다 **단백질바라는 하나의 제품군 안에서 완제품(FERT) 자재코드 3종**으로 관리한다.

**해외지사:** 일본 고객에게 수출한다는 이유만으로 일본 법인·회사코드를 반드시 만들어야 하는 것은 아니다. 현재는 국내 판매 시나리오를 먼저 구현하고, 해외영업 또는 해외법인 추가가 과제 요구사항인지 확인한 후 확장 범위를 정한다.

## 6. 자재마스터 구체화

**자재마스터란?** 제품과 재료를 SAP에서 구분하기 위한 기본정보. 오늘은 **자재명·자재유형(Type)·기본단위·자재그룹·평가클래스**를 어느 정도로 관리할지 결정하면 된다.

### 6-1. 보고서의 자재 목록

| 자재유형 | 개수 | 자재명(기존안) | 기본단위 |
|---|---:|---|---|
| **ROH 원재료** | 7 | WPC80, 수용성 식이섬유, 바인더 베이스, 단백질 크리스프, 카카오·모카·솔티드 캐러멜 향미 프리믹스 | KG |
| **HALB 반제품** | 7 | 공통 단백질 프리믹스 1종, 맛별 반죽 3종, 맛별 미포장 바 3종 | 반죽·프리믹스 KG, 미포장 바 EA |
| **FERT 완제품** | 3 | 카카오·모카·솔티드 캐러멜 크런치 단백질바 | EA |
| **HAWA 상품** | 2 | 셰이커 보틀, 스포츠 타월(외부에서 구매해 재판매) | EA |
| **VERP 포장재** | 4 | 맛별 인쇄필름 3종, 공용 골판지 운송박스 | 인쇄필름 M, 박스 EA |
| **합계** | **23** | 3주차 보고서에 기초한 검토 목록 | |

### 6-1-1. 원재료(ROH) — 7종

제품을 만들 때 투입하는 재료. **공통 원재료 4종 + 맛별 향미 원료 3종**이다.

| 자재코드(제안) | 자재명 | 자재유형 | 기본단위 | 자재그룹(제안) | 평가클래스 |
|---|---|---|---|---|---|
| RM-WPC-001 | 유청단백질농축물 WPC80 | ROH | KG | 단백질 원료 | MM·FI 확인 |
| RM-FBR-001 | 수용성 식이섬유 | ROH | KG | 식이섬유 원료 | MM·FI 확인 |
| RM-BND-001 | 단백질바용 바인더 베이스 | ROH | KG | 결합 원료 | MM·FI 확인 |
| RM-CRS-001 | 단백질 크리스프 | ROH | KG | 식감 원료 | MM·FI 확인 |
| RM-CCA-001 | 카카오 향미 프리믹스 | ROH | KG | 향미 원료 | MM·FI 확인 |
| RM-MOC-001 | 모카 향미 프리믹스 | ROH | KG | 향미 원료 | MM·FI 확인 |
| RM-SCA-001 | 솔티드 캐러멜 향미 프리믹스 | ROH | KG | 향미 원료 | MM·FI 확인 |

**수량 구분:** '7종'은 등록할 **자재 종류의 개수**이고, BOM에 들어갈 WPC80·식이섬유 등의 **실제 투입량(KG)**은 아직 결정되지 않았다. 원재료별 배합량은 PP·MM과 협의한다.

### 6-1-2. 반제품(HALB) — 7종

생산이 진행 중인 중간 제품. 기존 보고서의 **공통 프리믹스 1종 + 맛별 반죽 3종 + 맛별 미포장 바 3종**을 각각 표시했다.

| 자재코드(제안) | 자재명 | 자재유형 | 기본단위 | 자재그룹(제안) | 평가클래스 |
|---|---|---|---|---|---|
| SF-COM-001 | 공통 단백질 프리믹스 | HALB | KG | 공통 프리믹스 | MM·FI 확인 |
| SF-CCA-DOU | 카카오 단백질바 반죽 | HALB | KG | 맛별 반죽 | MM·FI 확인 |
| SF-MOC-DOU | 모카 단백질바 반죽 | HALB | KG | 맛별 반죽 | MM·FI 확인 |
| SF-SCA-DOU | 솔티드 캐러멜 단백질바 반죽 | HALB | KG | 맛별 반죽 | MM·FI 확인 |
| SF-CCA-BAR | 미포장 카카오 단백질바 | HALB | EA | 미포장 바 | MM·FI 확인 |
| SF-MOC-BAR | 미포장 모카 단백질바 | HALB | EA | 미포장 바 | MM·FI 확인 |
| SF-SCA-BAR | 미포장 솔티드 캐러멜 단백질바 | HALB | EA | 미포장 바 | MM·FI 확인 |

**단위가 다른 이유:** 프리믹스와 반죽은 **무게(KG)**로, 절단된 미포장 바는 **개수(EA)**로 관리하는 안이다. 예를 들어 반죽 몇 KG에서 미포장 바 몇 EA가 나오는지는 **1개 중량과 생산손실**이 정해져야 계산할 수 있다. 보고서에 없는 수율·중량은 임의로 입력하지 않는다.

**회의에서 확인:** 7종 모두를 SAP에서 **별도 생산·재고로 관리할지**, 일부는 실제 생산공정의 중간 단계로만 표현할지 PP 담당자와 결정한다.

### 6-1-3. 완제품(FERT) — 3종

생산과 **맛별 개별 포장**이 끝나 고객에게 판매할 수 있는 단백질바다.

| 자재코드(제안) | 완제품명(정정 제안) | 자재유형 | 기본단위 | 자재그룹(제안) | 평가클래스 |
|---|---|---|---|---|---|
| FG-CCA-001 | M&H 카카오 크런치 단백질바 | FERT | EA | 단백질바 완제품 | MM·FI 확인 |
| FG-MOC-001 | M&H 모카 크런치 단백질바 | FERT | EA | 단백질바 완제품 | MM·FI 확인 |
| FG-SCA-001 | M&H 솔티드 캐러멜 크런치 단백질바 | FERT | EA | 단백질바 완제품 | MM·FI 확인 |

**제품명 확인:** 3주차 보고서의 완제품 표에는 **카카오 제품명이 중복**되고 솔티드 캐러멜 브랜드명이 **M&G**로 기재되어 있다. 위 표는 원재료·반제품에 맞춘 **카카오·모카·솔티드 캐러멜 3종 및 M&H 표기 정정 제안**이므로 팀에서 확인한 뒤 확정한다.

**회의에서 확인:** 1개당 중량(g), 처음 생산할 수량(EA), 판매단위(EA), 판매가격, 1박스에 넣을 제품 수.

### 6-1-4. 상품(HAWA) — 2종

회사가 **직접 만들지 않고 외부에서 구매한 뒤 재판매**하는 제품으로, 단백질바 생산공정과 구분한다.

| 자재코드(제안) | 자재명 | 자재유형 | 기본단위 | 자재그룹(제안) | 평가클래스 |
|---|---|---|---|---|---|
| TG-SHK-001 | M&H 셰이커 보틀 | HAWA | EA | 재판매 상품 | MM·FI 확인 |
| TG-TWL-001 | M&H 스포츠 타월 | HAWA | EA | 재판매 상품 | MM·FI 확인 |

**회의에서 확인:** 1차 SAP 구현에 포함할지 여부. 포함한다면 외부 구매(MM) → 상품 재고 → 판매(SD) 흐름을 추가하며, **직접 제조하지 않으므로 단백질바와 같은 제조 BOM을 만들지 않는다.**

### 6-1-5. 포장재(VERP) — 4종

개별 포장에는 **맛별 인쇄필름**, 고객 납품에는 **공용 골판지 운송박스**를 사용한다는 안이다.

| 자재코드(제안) | 자재명 | 자재유형 | 기본단위 | 자재그룹(제안) | 평가클래스 |
|---|---|---|---|---|---|
| PK-CCA-001 | 카카오 크런치 인쇄필름 | VERP | M | 맛별 인쇄필름 | MM·FI 확인 |
| PK-MOC-001 | 모카 크런치 인쇄필름 | VERP | M | 맛별 인쇄필름 | MM·FI 확인 |
| PK-SCA-001 | 솔티드 캐러멜 인쇄필름 | VERP | M | 맛별 인쇄필름 | MM·FI 확인 |
| PK-BOX-001 | 공용 골판지 운송박스 | VERP | EA | 운송용 박스 | MM·FI 확인 |

**단위·수량 확인:** 인쇄필름의 기본단위가 **M(미터)**이므로 단백질바 **1개당 필름 몇 M**를 쓰는지 정해야 한다. 골판지 운송박스는 **1박스당 바 몇 EA**를 넣는지 결정한다. 이 박스를 제조 BOM에 넣을지, SD 배송용 포장재로 관리할지도 PP·MM·SD가 함께 정한다.

**평가클래스 공통 주의:** 표에서 'MM·FI 확인'이라고 적은 이유는 평가클래스가 **관리용 자재그룹과 달리 회계계정 결정에 연결**되기 때문이다. 실제 실습 SAP에서 사용 가능한 유형별 번호를 확인한 후 채운다. '자재그룹(제안)' 명칭은 아직 팀에서 확정된 그룹 코드가 아니다.

---

**이번 회의의 핵심 판단:** HALB 7종을 **실제로 각각 생산·보관할 자재로 모두 등록할지**, 일부는 Routing의 중간 작업으로 설명할지 결정한다. HAWA 2종은 직접 제조하지 않으므로 PP 생산오더 없이 구매·판매하는 **확장 시나리오**로 둘 수 있다.

### 6-2. 제품별 연결(구조만 제안)

    공통 원료 → 공통 단백질 프리믹스
       → 맛별 향미 프리믹스·바인더 등 투입 → 맛별 반죽
       → 냉각성형·절단 → 맛별 미포장 바
       → 같은 맛의 인쇄필름 사용 → 맛별 완제품

제품마다 **맛별 향미 원료와 맛별 인쇄필름이 달라지는 구조**다. 정확한 BOM 투입량, 1바의 중량, KG↔EA 환산, 필름 사용길이(M/EA), 운송박스 1개당 바 입수량은 **확인 필요**다. 보고서에 없는 배합수치를 임의로 확정하지 않는다.

### 6-3. 자재유형 / 자재그룹 / 평가클래스 차이

| 항목 | 쉬운 의미 | 오늘 준비할 내용 |
|---|---|---|
| **자재유형(Material Type)** | 원재료·반제품·완제품·상품·포장재 중 무엇인가 | ROH / HALB / FERT / HAWA / VERP |
| **자재그룹(Material Group)** | 비슷한 품목끼리 묶는 내부 관리용 분류 | 단백질 원료 / 향미 원료 / 반제품 / 완제품 / 상품 / 포장재 등 제안 |
| **평가클래스(Valuation Class)** | 자재의 재고금액이 어떤 회계계정으로 연결되는지 결정할 때 사용하는 분류 | **MM·FI 담당자가 실제 SAP 실습 시스템의 허용값 확인 후 확정** |

## 7. 네이밍 룰(코드 규칙) 제안

각자 다른 코드를 쓰지 않도록 **회사 접두어 MH + 업무별 숫자**, **자재유형 접두어 + 품목/맛 구분**으로 제안한다.

|---|---|---|

| Sales Organization | MH30 | 국내 영업조직 |
| Shipping Point | MH40 | 국내 출하지점 |
| Controlling Area | MH50 | 관리회계영역 |

| 자재코드 예시 | 의미 |
|---|---|

| FG-CCA-001 / FG-MOC-001 / FG-SCA-001 | 카카오 / 모카 / 솔티드 캐러멜 완제품 |

**확인 필요:** 코드 길이·형식·중복 여부·생성 권한은 수업 SAP에서 확인. 평가클래스 번호는 임의로 지정하지 않는다.
