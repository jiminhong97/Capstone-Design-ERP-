## 2. 실제 공정과 SAP 구현 범위

### 2.1 고단백 영양바 생산: 실제 제조방식에 근거한 공정

식품설비 기업 Bühler는 시리얼·단백질바 생산라인에서 곡물/결합제 혼합, 연속 슬래브 형태 성형, 냉각, 절단 등을 설명한다. 초콜릿 코팅은 제품에 따라 추가할 수 있는 단계다.

실제 작업 예시:

    원재료 수령·보관
      → 계량
      → 곡물·단백질과 결합시럽 혼합
      → 평평한 바 형태로 압착·성형
      → 냉각
      → 일정한 규격으로 절단
      → 개별 밀봉포장
      → 완제품 입고

**SAP 설계안(4개 Operation):**

| 작업순서 | 작업장(Work Center) | ERP에서 묶어 관리할 실제 작업 |
|---|---|---|
| 0010 | WC01 MIX | 계량, 시럽 투입, 원재료 혼합 |
| 0020 | WC02 FORM | 바 형태로 성형·압착 |
| 0030 | WC03 CUT | 냉각, 규격 절단 |
| 0040 | WC04 PACK | 개별 포장, 표기·최종 확인 |

이것은 '원재료를 받아 포장만 하는 회사'가 아니라 **혼합·성형·절단을 직접 하는 제조업체**다. 장비 온도·압력, 레시피 안정성, 품질 검사 세부는 실제 제조에서 중요하지만, SAP 초보 수업의 독립 Operation으로 모두 만들 필요는 없다. **코팅 제품을 만들면 코팅 작업과 해당 원재료/공정을 별도로 추가**한다.

### 2.2 분말과 결합제의 역할

- 압착 성형되는 영양바에는 곡물 및 단백질 원료 외에 시럽 등의 **결합재(binder)**가 쓰일 수 있다.
- 실제 영양바는 제품별 배합과 생산수율, 알레르기 유발물질, 안정성 검증이 필요하다.
- 프로젝트에서는 가상의 대표 원료를 선정하되, 이를 **검증된 상업용 식품 배합**으로 주장하지 않는다.

### 2.3 추천 구현 규모

| 항목 | 1차 목표 |
|---|---|
| 회사코드 / 생산 플랜트 | 각 1개 |
| 저장위치 | 원재료/포장재/완제품 최대 3개 |
| 완제품 | 3개 맛 |
| 원재료 | 공통 4개 + 제품별 맛 원료 3개 = 7개 |
| 포장재 | 개별 포장지 1종 |
| 반제품 | 0개로 시작; 별도 생산·보관이 필요하면 1개 |
| 상품(재판매용 구매완제품) | 통합 테스트 1차 범위 제외 |
| 공급업체 | 2~3개 가상 공급업체 |
| 고객 | B2B 고객 1~2개부터 |
| 판매채널 | 처음 1개로 테스트, 가능하면 2개로 확장 |
| 공정(Operation) | 4개 |

## 3. 완제품 3종 및 자재마스터 초안

### 3.1 맛과 완제품

- **FG-CHO-050**: 초코 고단백 영양바, 50 g, 기본단위 EA(개)
- **FG-NUT-050**: 피넛 고단백 영양바, 50 g, 기본단위 EA
- **FG-CIN-050**: 시나몬 고단백 영양바, 50 g, 기본단위 EA

세 제품 모두 같은 **혼합 → 성형 → 냉각·절단 → 포장** 공정을 사용한다. 단, 실제 생산에서는 맛 전환 시 세척, 알레르기 교차접촉 방지 등이 필요하다. 이 점은 현장 운영수칙으로 별도 설명할 수 있다.

### 3.2 초안 자재 목록

| 자재코드(제안) | 자재명 | SAP 자재유형(안) | 기본단위 | 자재그룹(분류 예시) | 비고 |
|---|---|---|---|---|---|
| RM-OAT-001 | 압착 귀리 | ROH(원재료) | KG | MG-GRAIN | 공통 |
| RM-PRO-001 | 단백질 원료 | ROH | KG | MG-PROTEIN | 공통 |
| RM-SYR-001 | 결합시럽 | ROH | KG | MG-BINDER | 공통 |
| RM-OIL-001 | 식물성유지 | ROH | KG | MG-OIL | 공통 |
| RM-CHO-001 | 코코아 분말 | ROH | KG | MG-FLAVOR | 초코 맛 |
| RM-NUT-001 | 땅콩 분말 | ROH | KG | MG-FLAVOR | 피넛 맛 |
| RM-CIN-001 | 시나몬 혼합분말 | ROH | KG | MG-FLAVOR | 시나몬 맛 |

**현재 11종(ROH 7 + VERP 1 + FERT 3).** 원료 수를 적게 잡기 위한 교육용 구성이며 실제 영양바의 모든 첨가물·영양성분·레시피를 나타내지 않는다. 공급업체는 곡물/단백질, 기타 식품원료, 포장재 업체 등 **업종별 가상 Vendor**로 설정하면 된다. 실재 특정 업체와 거래하는 것으로 기재하지 않는다.

### 3.3 꼭 구분해야 할 세 가지

- **자재유형(Material Type):** 구매 원료 ROH, 반제품 HALB, 완제품 FERT, 외부구매 재판매상품 HAWA, 포장재 VERP처럼 SAP 처리 방식의 범주.
- **자재그룹(Material Group):** 원재료/포장/완제품, 또는 곡물/단백질/향미 등 내부의 관리·구매용 그룹. 위의 MG-... 코드는 **우리 팀의 제안 코드**이며 SAP 기본 코드가 아니다.
- **평가클래스(Valuation Class):** 재고·원가의 **회계계정 자동 결정에 사용하는 분류**. 자재그룹과 같은 개념이 아니다. 실제 시스템의 허용 평가클래스와 FI 계정결정 설정을 확인하기 전에는 임의 숫자를 확정하지 않는다.

**오늘 FI·MM 담당과 정할 일:** 실제 연습 SAP에서 ROH/VERP/FERT용으로 **허용된 평가클래스 번호**를 조회하고 재고계정과 연결할 것. 시스템에 없는 3000/7900 등의 번호를 설계 확정값처럼 입력하지 말 것.

## 4. BOM, 반제품, 상품 및 포장재

### 4.1 완제품별 BOM: 구조 예시

다음 수치는 **설계 구조를 설명하기 위한 임시 예시**이며, 50 g × 100개 = 5.0 kg의 목표 중량과 같은 양을 투입하도록 가정했다. **공정 손실·수분 변화·실제 배합비는 반영하지 않았다.** 실제 생산수율을 확인하면 조정해야 한다.

| 재료 / 바 100개 생산 기준 | 초코 100 EA | 피넛 100 EA | 시나몬 100 EA |
|---|---:|---:|---:|
| 압착 귀리(RM-OAT-001) | 1.80 KG | 1.80 KG | 1.80 KG |
| 단백질 원료(RM-PRO-001) | 1.50 KG | 1.50 KG | 1.50 KG |
| 결합시럽(RM-SYR-001) | 1.20 KG | 1.20 KG | 1.20 KG |
| 식물성유지(RM-OIL-001) | 0.20 KG | 0.20 KG | 0.20 KG |
| 코코아 분말(RM-CHO-001) | 0.30 KG | — | — |
| 땅콩 분말(RM-NUT-001) | — | 0.30 KG | — |
| 시나몬 혼합분말(RM-CIN-001) | — | — | 0.30 KG |
| 개별 포장지(PK-WRP-001) | 100 EA | 100 EA | 100 EA |

**BOM 헤더 수량 = 해당 FG 100 EA**, 원료는 KG, 포장지는 EA로 입력한다. 표의 각 열이 **서로 다른 FG의 BOM**이다. '공정이 같음'이 'BOM도 정확히 1개'라는 뜻은 아니다. 제품마다 적어도 향미 재료가 다르므로 BOM 구성이 달라진다.

### 4.2 반제품(HALB)은 넣을까?

**1차 구현에서는 넣지 않는 안을 제안한다.** 혼합물은 생산라인에서 성형·절단으로 이어지고 별도 재고·판매 대상으로 관리하지 않는 설정이다. 작업 사이의 모든 중간 상태를 반제품 자재마스터로 만들 필요는 없다.

추가한다면 '공통 바 베이스'를 별도 생산·재고보관하고 맛별 완제품 공정에 투입하는 **실제 운영 이유**가 있어야 한다. 이 경우 베이스의 독립 BOM, 생산오더, 재고입고 및 맛별 FG의 상위 BOM이 추가돼 난이도가 올라간다.

### 4.3 떼다 파는 상품(HAWA)은 넣을까?

**1차 테스트에서는 제외**한다. 우리 회사 제조제품이 중심이므로, 외부 브랜드 단백질 음료를 사 와서 판다면 HAWA 1종을 2차 확장으로 추가할 수 있다. HAWA는 **회사에서 생산하지 않는 구매완제품**이므로 제조용 BOM이나 PP 생산오더 대상이 아니다. 단순 SD 판매 + MM 구매 시나리오를 별도로 하나 더 보여주고 싶을 때만 사용한다.

### 4.4 포장재와 판매단위

- 개별 밀봉 포장지는 제조 BOM에 **100 EA / 바 100 EA**로 포함.
- 배송용 택배상자 또는 10개들이 진열박스는 **개별 바 제조에 1개씩 들어가는 자재가 아님**. 우선 SD 출하포장용 자재로 별도 검토하거나, 10개 묶음을 별도 판매제품으로 만들 때만 포장 BOM을 정의한다.
- B2B 고객이 '10박스'를 주문한다고 할 때 **1박스 = 바 10개인지, 1박스 자체가 별도 판매자재인지** 먼저 정한다. 초기 통합 테스트는 **바 100 EA**를 주문·출고하는 것으로 통일한다.

## 5. 코드 네이밍 및 모듈별 조직구조(제안)

### 5.1 네이밍 규칙

- 동일한 4자리 조직 코드라도 역할이 다르므로 회의용 예시로 서로 다른 접두를 사용한다.
- **공유 실습 시스템에 기존 코드·공동 클라이언트 번호가 있을 수 있으므로 SAP 입력 전에 중복/권한을 확인**한다.
- 코드 이름은 제품명/브랜드명에서 과도한 한글·공백을 피하고, 자재코드는 **[유형]-[품목]-[규격]** 원칙으로 만든다.

| 조직 또는 마스터 | 예시 코드 | 설명 | 담당 확인 |

| 회사코드(Company Code) | MH01 | 머슬 앤 허슬 한국법인 | FI |
| 관리회계영역(Controlling Area) | MH50 | 관리회계 조직 | CO/FI |

| 포장재 저장위치 | PK01 | 포장재 재고(선택) | MM |
| 완제품 저장위치 | FG01 | 완제품 재고 | MM/SD |
| 구매조직(Purchasing Org.) | MH20 | 국내 구매조직 | MM |

    MH01 회사코드(FI)
      ├─ MH50 관리회계영역(CO) 연계
      ├─ MH10 생산 플랜트(PP/MM)
      │   ├─ RM01 원재료 저장위치

      │   └─ FG01 완제품 저장위치
      ├─ MH20 구매조직(MM) → MH10 구매대상 플랜트
      └─ MH30 영업조직(SD)
          ├─ 10 도매 / 20 온라인(선택)
          ├─ 01 영양바 제품군
          └─ MH40 출하지점 → MH10 플랜트 출하

**첫 Sales Area = MH30 / 10 / 01** (영업조직 / 유통경로 / 제품군). 온라인을 추가하면 **MH30 / 20 / 01**이 추가되며, 그 경우 관련 고객/자재 영업데이터의 해당 판매영역 확장도 확인해야 한다.

**중요:** MM 저장위치는 SAP의 창고관리 세부 물리 위치 그 자체가 아니며, 생산라인별 모든 작업장을 각각 Storage Location으로 만들 필요도 없다. FI/CO의 G/L, Chart of Accounts, Fiscal Year Variant, Credit Control 등은 수업 제공 기준값과 선행 Config에 맞춰 담당자가 검증해야 한다.

## 6. 모듈별 AS-IS → TO-BE 초안

> **실제 기업에서 발생했다고 검증된 사실이 아니다.** 9월 8일 핸드북에서 식별한 '업무 간 단절, 수작업 오류, 납품 지연, 회계 통제'를 가상 고객사 머슬 앤 허슬에 적용한 **시나리오 가설**이다. 인터뷰·실측 수치가 없는 한 '현재 발생한다'보다는 '이런 상황이 발생하도록 AS-IS를 설정한다'로 설명한다.

| 모듈 | 가상 고객사의 AS-IS 문제 | 제안 TO-BE와 시연 |
|---|---|---|
| MM | 구매·입고·반품 기록이 부서별 파일에 분산돼 실제 원재료 재고와 발주 상태 확인이 늦음 | 구매요청 → 구매오더 → 입고 문서 연결; 원재료 가용수량 확인 |
| PP | 맛별 판매주문이 생산계획에 늦게 전달돼 특정 맛의 원료만 부족하고 납기 지연 | 맛별 FG/BOM을 구분하고 부족 수량 기반 생산계획·오더 생성 |
| SD | 도매 주문을 재고 확인 없이 확정해 잘 팔리는 맛만 품절, 분할출고·고객 불만 | 주문 입력 때 품목·수량·납기 확인, 재고와 출고 상태 추적 |
| FI | 입고·반품 정보를 수기로 전달해 구매송장/매출청구 수정작업 발생, 승인 기준 일관성 부족 | PO·입고·송장 정합성 및 SD 청구와 회계전표 연결; 실제 구현 가능한 승인통제 범위 별도 확인 |
| CO | 맛별 원료비와 생산 관련 비용을 합산하기 어려워 어느 SKU의 원가가 높은지 늦게 확인 | 3개 맛의 BOM 기반 원가 추정과 제품별 제조원가 비교(설정·데이터 확보 범위 확인) |

### 산업 특화 문제 1: 맛별 원료 부족과 오출고

- 예시: 피넛바 100 EA의 수주가 들어왔는데 피넛 분말의 재고가 부족하다. 기존에는 '영양바 총재고'만 확인해 피넛 맛의 생산 가능 여부를 놓친다.
- 다른 예시: 초코와 피넛 포장지가 비슷해 수작업 분류 시 잘못된 맛의 제품이 출고된다.
- 개선 방향: **맛별로 서로 다른 FG 자재코드와 BOM**을 사용하고, 판매오더·생산오더·출고를 동일 FG 코드로 연결한다.
- 피넛의 **알레르기 교차접촉·표시** 문제는 중요하지만, 기본 SAP SD가 자동으로 모두 차단한다고 주장하지 않는다. 생산 세척·현장 검수 규칙과 추가 품질관리 범위를 따로 제시한다.

### 산업 특화 문제 2: 유통기한·생산 LOT

- 예시: 같은 초코바라도 생산일이 다른 LOT가 있고, 이전 수작업 출고에서는 먼저 만든 재고보다 최근 재고를 출고한다.
- 개선 방향: 수업 시스템에서 가능하면 **Batch/LOT 식별 + 유통기한(SLED) 조회/출고 확인**을 적용한다.
- **주의:** SAP의 유통기한 자동 체크·배치선정은 해당 자재의 배치관리/유통기한 설정 및 출고 프로세스 구성에 따라 달라진다. 기능 확인 전에는 '이미 자동 FEFO가 된다'고 쓰지 않는다. 구현이 어렵다면 **수기 LOT 대장·출고 체크리스트를 AS-IS/TO-BE 설명용으로만** 사용하고, SAP 통합실습은 기본 재고·납품까지로 제한한다.

## 7. SD 담당(홍지민) 회의 준비 및 첫 통합 시나리오

### 내 담당에서 결정할 기본정보

| 항목 | 제안 |
|---|---|
| 영업조직 | MH30 국내영업 |
| 유통경로 1차 | 10 도매 |
| 제품군 | 01 영양바 |
| 출하지점 | MH40 |
| 출고 플랜트 / 저장위치 | MH10 / FG01 |
| B2B 고객 | CU-001 가상 편의점 유통사 |
| 판매자재 | FG-CHO-050 / FG-NUT-050 / FG-CIN-050 |
| 판매단위 | EA(바 1개) |
| 온라인 채널 | 기본 기능 검증 후 확장; 자사몰 자동 연동을 실제 구현한다고 가정하지 않음 |

### 첫 번째 통합 테스트: 피넛바 100개 주문

1. **SD**: 가상 유통사 CU-001로부터 피넛바 100 EA 수주(Sales Order).
2. **SD/MM/PP**: 피넛바 완제품 FG 재고 및 원재료 가용재고 확인. 필요하면 PP에서 생산 100 EA 계획.
3. **MM**: 피넛 분말 또는 공통 원료 부족 시 구매요청 → 발주 → 입고.
4. **PP**: FG-NUT-050의 BOM을 기준으로 생산오더를 만들고 생산·완제품 입고.
5. **SD**: 출고문서(Delivery) → Picking → Post Goods Issue(출고전기).
6. **SD/FI**: Billing(고객 청구) → FI 매출채권 생성 및 고객 대금입금 테스트(실습 범위 내).
7. **CO**: 피넛바의 자재비와 생산비를 비교·분석(해당 CO 설정이 준비된 경우).

**처음부터 주문 생성만으로 MM 발주와 PP 생산오더가 '완전 자동으로 실행된다'고 발표하면 안 된다.** 수요연계, MRP 실행, 계획오더 전환 및 마스터데이터 설정을 확인한 후 자동화 범위를 결정한다.

### SD가 다른 담당자에게 물어볼 것

- **PP:** 맛별 FG 자재코드, 생산 리드타임, 1차 생산 가능 수량, 생산·입고 시점은?
- **MM:** MH10/FG01에서 판매 가능한 재고를 어떻게 관리하는지? 재고부족 때 구매/입고 일정은?
- **FI:** 판매청구 시 필요한 매출·매출채권·세금 관련 계정과 고객 회계마스터는?
- **CO:** 맛별 원가 비교에 필요한 BOM 수량/표준원가·원가센터는?
- **전원:** 100 EA를 납품하는 표준 시나리오 하나를 먼저 통과시키고, 나중에 맛별 품절·LOT·온라인을 추가할 것인가?

## 8. 만약 최종 제품이 봉지형 그래놀라 시리얼이라면

**이 경우 위의 영양바용 BOM/공정을 그대로 사용하면 안 된다.** 봉지형 그래놀라는 바처럼 압착·규격 절단·개별 래핑하는 제품이 아니다.

### 실제 공정 근거를 반영한 그래놀라형 설계

Coperion의 산업용 loose granola 설명은 **원료 혼합 → 굽기 → 냉각 → 큰 덩어리를 작은 클러스터로 부수기(kibbling) → 후공정/포장** 구조를 설명한다.

**SAP 4개 Operation 제안:**

| 순서 | 작업장 | 내용 |
|---|---|---|
| 0010 | WC01 MIX | 귀리·씨앗·견과류·시럽 등을 계량하고 혼합 |
| 0020 | WC02 BAKE | 팬/벨트에 펼친 혼합물 굽기 |
| 0030 | WC03 COOL | 냉각, 그래놀라 클러스터 크기 조정 |
| 0040 | WC04 PACK | 필요 시 건조과일/초코칩 후첨, 계량·밀봉 포장 |

맛 3종 예시: **오리지널 넛 / 코코아 / 베리**. 공통 구운 베이스를 사용하되, 실제 레시피에 맞게 맛별 견과류·코코아 또는 **냉각 후 건조과일**을 다르게 넣는 방식이다. 초콜릿칩이나 건조과일을 언제 투입할지는 식품 원료 특성에 맞게 선정한다.

**봉지형 그래놀라 FG는 250 g 1봉 = 1 EA**와 같이 정의한다. 귀리·시럽·유지·견과류·씨앗·맛별 토핑·파우치를 자재마스터로 구분한다. 굽는 과정에서 수분이 달라지므로 상위 영양바의 임시 '100개 × 50g' BOM 수치를 재사용하지 않는다. 만약 베이스를 **별도 생산하여 재고에 보관**한다면 공통 구운 그래놀라 베이스 1종을 HALB로 추가할 수 있고, 단순 연속공정이면 생략할 수 있다.

**회의에서 꼭 선택:** 영양바(50g, 바 3종) / 봉지형 그래놀라(250g, 시리얼 3종) 중 하나를 공식 회사설계의 기준으로 고정해야 자재코드·생산공정·SD 판매단위·원가계산이 서로 맞는다.
